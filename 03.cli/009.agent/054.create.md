---
title: Agent Create
description: Create an agent session, optionally seeded with a context workflow
---

### Usage

```bash [Terminal]
dxflow agent create [OPTIONS]
```

Alias: `dxflow agent new`.

### Options

| Flag | Shorthand | Description | Type | Default |
|------|-----------|-------------|------|---------|
| `--identity` | `-i` | Session identity; folded to the engine's identity shape | `string` |  |
| `--workflow` | `-w` | Context workflow identity for the session; folded the same way | `string` |  |

Both are folded before use, so `--identity my-session` creates `mysession`. See [Identities](/docs/advanced/concepts#identities).

A session is one conversation that can create and operate several workflows. `--workflow` is optional — it points the session at a workflow to start with, so you can ask about it right away. Without it, the agent creates a new workflow from your first request. Either way, when you don't name a workflow the agent acts on the one you used most recently.

### Example

```bash [Terminal]
dxflow agent create

dxflow agent create --workflow ebc954e7f50e
```
