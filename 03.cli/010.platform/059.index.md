---
title: Platform
description: Connect this engine to a dxflow platform account
---

### Usage

```bash [Terminal]
dxflow platform
```

### Subcommands

| Command | Description | Help |
|---------|-------------|------|
| [**login**](/docs/cli/platform/login) | Connect engine | `dxflow platform login --help` |
| [**info**](/docs/cli/platform/info) | Get platform info | `dxflow platform info --help` |
| [**logout**](/docs/cli/platform/logout) | Release engine | `dxflow platform logout --help` |

### Shortcuts

`login` and `logout` answer at the root as well, with the same flags:

```bash [Terminal]
dxflow login
dxflow logout
```
