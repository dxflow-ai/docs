---
title: Key Generate
description: Generate new rsa key pair locally
---

### Usage

```bash [Terminal]
dxflow key generate [NAME]
```

Alias: `dxflow key gen`.

### Arguments

| Argument | Description |
|----------|-------------|
| `NAME` | Base name for the pair, default `rsa`. Writes `<NAME>.pem` and `<NAME>.pub` into the current directory |
