---
title: Key Register
description: Register new authentication key
---

### Usage

```bash [Terminal]
dxflow key register <KEY> [OPTIONS]
```

Alias: `dxflow key add`.

### Arguments

| Argument | Description |
|----------|-------------|
| `KEY` | Path to the public key file to authorize. Must be a file, not a directory — its contents are read and sent to the engine |

### Options

| Flag | Shorthand | Description | Type | Default |
|------|-----------|-------------|------|---------|
| `--identity` | `-i` | Key identity | `string` |  |
| `--permissions` | `-p` | Key permissions | `strings` | `[]` |
