---
title: License Activate
description: Issue and activate the license for this engine
---

### Usage

```bash [Terminal]
dxflow license activate [OPTIONS]
```

Alias: `dxflow license active`.

### Options

| Flag | Shorthand | Description | Type | Default |
|------|-----------|-------------|------|---------|
| `--no-download` |  | Skip downloading license from server | `bool` | `false` |
| `--retry` |  | Times to recheck the certificates awaiting issuance | `int` | `5` |

The engine issues its own license against the account holding it, so connect it first with `dxflow login`. The identity comes from the platform session, not from an argument.

Activation also collects the certificate for every [link](/docs/advanced/links) the license carries and registers the address the platform observes. Issuance happens on the platform side and takes a moment, so the command rechecks five times by default, two seconds apart, and reports where it stands on a status line it redraws in place:

```
● 2 of 4 certificates ready, c.dakumori.link.dxflow.ai awaiting issuance, rechecking in 1s
```

`--retry` sets how many rechecks to make — anything below `1` counts as one, and the cap is `60`, roughly two minutes of waiting. The delay between them is fixed at two seconds.

**CTRL+C** during a recheck gives the terminal straight back. Certificates still awaiting issuance when the last recheck passes are collected by running the command again, which names them.
