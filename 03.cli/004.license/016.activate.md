---
title: License Activate
description: Download and activate the license issued for this engine
---

### Usage

```bash [Terminal]
dxflow license activate [OPTIONS]
```

### Options

| Flag | Shorthand | Description | Type | Default |
|------|-----------|-------------|------|---------|
| `--name` |  | License name used to authorize the download | `string` | hostname |
| `--no-download` |  | Skip downloading license from server | `bool` | `false` |
