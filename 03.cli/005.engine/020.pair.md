---
title: Engine Pair
description: Pair a console session with a single use code
---

### Usage

```bash [Terminal]
dxflow engine pair [OPTIONS]
```

### Options

| Flag | Shorthand | Description | Type | Default |
|------|-----------|-------------|------|---------|
| `--permissions` | `-p` | Session permissions | `strings` | `[]` |
| `--lifetime` | `-l` | Session lifetime | `string` | `` |

### Description

Prints a single use code that signs a browser console in without a private key. Enter the code in the console, then approve the request that appears on this terminal.

Sessions run for **1 hour** unless `--lifetime` sets otherwise, accepting **1 minute** to **24 hours**. Permissions default to `SHELL`, `ARTIFACT`, `RUNTIME`, `WORKFLOW`, and `AGENT`.

The code lasts 30 seconds, and approving gets a further 30 seconds once a console claims it. Approval, rejection, and expiry all consume the code, so each session needs a fresh run.

Requires a running engine, started in either the foreground or the background.

```bash [Terminal]
● Pairing
  Permissions  SHELL, ARTIFACT, RUNTIME, WORKFLOW, AGENT
  Code         K7QM3XPD
  Waiting 30s for a console to use the code

● Pairing request
  Address      203.0.113.9
  Agent        Mozilla/5.0 (Macintosh; Intel Mac OS X 10_15_7)
  Approve? [y/N] y
Pairing approved: the console is signed in
```
