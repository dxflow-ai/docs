---
title: Engine
description: Manage engine information, updates, and monitoring
---

### Usage

```bash [Terminal]
dxflow engine
```

### Subcommands

| Command | Description | Help |
|---------|-------------|------|
| [**token**](/docs/cli/engine/token) | Generate auth token | `dxflow engine token --help` |
| [**pair**](/docs/cli/engine/pair) | Pair a console | `dxflow engine pair --help` |
| [**healthcheck**](/docs/cli/engine/healthcheck) | Verify health | `dxflow engine healthcheck --help` |
| [**ping**](/docs/cli/engine/ping) | Check connectivity | `dxflow engine ping --help` |
| [**info**](/docs/cli/engine/info) | Get engine info | `dxflow engine info --help` |
| [**stats**](/docs/cli/engine/stats) | Show live engine statistics | `dxflow engine stats --help` |
| [**update**](/docs/cli/engine/update) | Update engine | `dxflow engine update --help` |

### Shortcuts

`token`, `healthcheck`, `ping`, and `stats` answer at the root as well, with the same flags:

```bash [Terminal]
dxflow token
dxflow healthcheck
dxflow ping
dxflow stats
```
