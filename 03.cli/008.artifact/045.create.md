---
title: Artifact Create
description: Create new artifact
---

### Usage

```bash [Terminal]
dxflow artifact create <IDENTITY> [OPTIONS]
```

Alias: `dxflow artifact touch`.

### Arguments

| Argument | Description |
|----------|-------------|
| `IDENTITY` | Path of the artifact to create. Pass `--directory` to make a directory instead of a file |

### Options

| Flag | Shorthand | Description | Type | Default |
|------|-----------|-------------|------|---------|
| `--directory` | `-d` | Make a directory | `bool` | `false` |
| `--force` | `-f` | Force creation if exists | `bool` | `false` |
