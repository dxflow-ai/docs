---
title: Artifact Upload
description: Upload artifact to remote storage
---

### Usage

```bash [Terminal]
dxflow artifact upload <SOURCE> [IDENTITY] [OPTIONS]
```

Alias: `dxflow artifact push`.

### Arguments

| Argument | Description |
|----------|-------------|
| `SOURCE` | Local file to upload. Directories are rejected |
| `IDENTITY` | Destination path on the engine, default `./`. A path ending in `/` or carrying no extension is treated as a directory, and the source's file name is appended to it |

### Options

| Flag | Shorthand | Description | Type | Default |
|------|-----------|-------------|------|---------|
| `--force` | `-f` | Force creation if exists | `bool` | `false` |
