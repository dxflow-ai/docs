---
title: Artifact Download
description: Download artifact from remote storage
---

### Usage

```bash [Terminal]
dxflow artifact download <IDENTITY> [DESTINATION] [OPTIONS]
```

Alias: `dxflow artifact pull`.

### Arguments

| Argument | Description |
|----------|-------------|
| `IDENTITY` | Artifact to download, as listed by `dxflow artifact list` |
| `DESTINATION` | Local path to write to, default `./`. A path ending in `/` or carrying no extension is treated as a directory, and the artifact's file name is appended to it. An existing destination fails unless `--force` is passed |

### Options

| Flag | Shorthand | Description | Type | Default |
|------|-----------|-------------|------|---------|
| `--force` | `-f` | Force creation if exists | `bool` | `false` |
