---
title: Artifact Rename
description: Rename or move artifact
---

### Usage

```bash [Terminal]
dxflow artifact rename <IDENTITY> <NEW_IDENTITY>
```

Alias: `dxflow artifact mv`.

### Arguments

| Argument | Description |
|----------|-------------|
| `IDENTITY` | Artifact to rename |
| `NEW_IDENTITY` | Its new path. Moving between directories is a rename |
