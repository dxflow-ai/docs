---
title: Artifact Zip
description: Compress artifact into zip archive
---

### Usage

```bash [Terminal]
dxflow artifact zip <IDENTITY> [OPTIONS]
```

### Arguments

| Argument | Description |
|----------|-------------|
| `IDENTITY` | Artifact to compress. The archive is written alongside it as `<IDENTITY>.zip` |

### Options

| Flag | Shorthand | Description | Type | Default |
|------|-----------|-------------|------|---------|
| `--quiet` | `-q` | Suppress progress output | `bool` | `false` |
