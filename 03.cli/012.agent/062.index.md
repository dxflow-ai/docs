---
title: Agent
description: Create and operate workflows with an LLM agent
---

### Usage

```bash [Terminal]
dxflow agent
```

### Subcommands

| Command | Description | Help |
|---------|-------------|------|
| [**create**](/docs/cli/agent/create) | Create a session | `dxflow agent create --help` |
| [**prompt**](/docs/cli/agent/prompt) | Advance a session one turn | `dxflow agent prompt --help` |
| [**list**](/docs/cli/agent/list) | List sessions | `dxflow agent list --help` |
| [**inspect**](/docs/cli/agent/inspect) | Inspect a session | `dxflow agent inspect --help` |
| [**remove**](/docs/cli/agent/remove) | Delete a session | `dxflow agent remove --help` |
