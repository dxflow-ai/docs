---
title: Agent Inspect
description: Show a session's identity, type, binding, and usage
---

### Usage

```bash [Terminal]
dxflow agent inspect <IDENTITY>
```

`IDENTITY` is the session to inspect. The output lists its identity, type, bound workflow, creation time, and token usage. Use [history](/docs/cli/agent/history) for the conversation turns.

### Example

```bash [Terminal]
dxflow agent inspect edb4311ad2f1
```
