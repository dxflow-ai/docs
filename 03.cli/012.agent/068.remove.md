---
title: Agent Remove
description: Delete an agent session
---

### Usage

```bash [Terminal]
dxflow agent remove <IDENTITY>
```

Alias: `dxflow agent rm`.

`IDENTITY` is the session to delete. This removes the session and its history; the bound workflow is not affected.

### Example

```bash [Terminal]
dxflow agent remove edb4311ad2f1
```
