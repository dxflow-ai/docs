---
title: Agent Create
description: Create an agent session, optionally bound to a workflow
---

### Usage

```bash [Terminal]
dxflow agent create [OPTIONS]
```

### Options

| Flag | Shorthand | Description | Type | Default |
|------|-----------|-------------|------|---------|
| `--identity` | `-i` | Session identity | `string` | `` |
| `--workflow` | `-w` | Workflow identity to bind | `string` | `` |

The session's phase is derived from the bound workflow: with no `--workflow` it starts in **design**; a bound workflow puts it in **deploy**, or **debug** once a step has failed.

### Example

```bash [Terminal]
dxflow agent create

dxflow agent create --workflow ebc954e7f50e
```
