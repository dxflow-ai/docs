---
title: Agent List
description: List agent sessions
---

### Usage

```bash [Terminal]
dxflow agent list [OPTIONS]
```

Alias: `dxflow agent ls`.

### Options

| Flag | Shorthand | Description | Type | Default |
|------|-----------|-------------|------|---------|
| `--type` | `-t` | Filter by session type (`design` or `deploy`) | `string` | `` |

### Example

```bash [Terminal]
dxflow agent list

dxflow agent ls --type deploy
```
