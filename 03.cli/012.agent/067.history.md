---
title: Agent History
description: List an agent session's conversation turns
---

### Usage

```bash [Terminal]
dxflow agent history <IDENTITY>
```

`IDENTITY` is the session. The output lists the session's conversation turns, each turn's side over its message. Use [inspect](/docs/cli/agent/inspect) for the session's identity, type, binding, and usage.

### Example

```bash [Terminal]
dxflow agent history edb4311ad2f1
```
