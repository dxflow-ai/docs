---
title: Workflow Hub Search
description: Search the hub catalog for workflow templates
---

### Usage

```bash [Terminal]
dxflow workflow hub search [QUERY]
```

`QUERY` is optional; an empty query lists every template. Matching is substring and case-insensitive across name, description, tags, and category.

### Output

```text [Terminal]
● workflow-name
  Workflow description
  https://raw.githubusercontent.com/dxflow-ai/hub/main/<category>/<workflow-name>/index.md
```

One block per match — the name, its description, and the source URL of the entry document.
