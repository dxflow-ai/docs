---
title: Workflow Start
description: Start workflow from first step
---

### Usage

```bash [Terminal]
dxflow workflow start <IDENTITY> [OPTIONS]
```

### Options

| Flag | Shorthand | Description | Type | Default |
|------|-----------|-------------|------|---------|
| `--override` | `-o` | Override value as `key=value`; repeatable | `stringSlice` | `` |

Override keys are `env.<step>.<VAR>` or `resource.<step>.<cpu\|memory\|gpu>`, scoped to a step by its `name`. The values are written to the workflow's `workflow.ini` before it starts and applied only at launch — they never modify the workflow definition (`workflow.json`). An unknown step `name` or an invalid `cpu`/`memory`/`gpu` value fails the start.

### Example

```bash [Terminal]
dxflow workflow start fastqc \
    --override env.fastqc.THREADS=8 \
    --override resource.fastqc.cpu=8
```
