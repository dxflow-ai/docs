---
title: Platform Logout
description: Release this engine from the account holding it
---

### Usage

```bash [Terminal]
dxflow platform logout
```

### Output

```text [Terminal]
Platform released: this engine is free to connect again
```

An engine identity is claimed once, so releasing it is what lets another account connect the same machine. The account holding it can do the same from dxflow platform.

`dxflow config unset platform-token` forgets the session on this host alone and leaves the identity claimed.
