---
title: Runtime docker logout request
description: Request of logout runtime docker
---

### Endpoint

```bash
PUT /api/runtime/docker/logout/
```

### Auth

```bash
Authorization: Bearer ${token}
```

### Response

```json [Json]
[
    {
        "kind": "status",
        "payload": {
            "code": 0,
            "message": ""
        }
    },
    {
        "kind": "entity",
        "payload": ""
    }
]
```

### Notes

- Runtime Permission Required
