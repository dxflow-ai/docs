---
title: Workflow hub search request
description: Request of search hub workflow
---

### Endpoint

```bash
GET /api/workflow/hub/search/
```

### Auth

```bash
Authorization: Bearer ${token}
```

### Query Parameters

| Key | Default | Description |
|-----|---------|-------------|
| query |  | Optional; empty or `*` returns every template. Substring match across name, description, tags, and category |

### Response

```json [Json]
[
    {
        "kind": "status",
        "payload": {
            "code": 0,
            "message": ""
        }
    },
    {
        "kind": "total",
        "payload": {
            "value": 0
        }
    },
    {
        "kind": "entity",
        "payload": {
            "description": "",
            "name": "",
            "url": ""
        }
    }
]
```

### Notes

- Workflow Permission Required
- Catalog is read live from the [dxflow hub](https://github.com/dxflow-ai/hub); drafts (entries without a `Configuration` block) are excluded.
