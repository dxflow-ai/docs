---
title: Engine key unregister request
description: Revoke an authorized key by identity
---

### Endpoint

```bash
DELETE /api/engine/key/
```

### Auth

```bash
Authorization: Bearer ${token}
```

### Query Parameters

| Key | Default |
|-----|---------|
| key |  |
| identity |  |

Provide either the public `key` or its `identity`; the matching key is unregistered.

### Response

```json [Json]
[
    {
        "kind": "status",
        "payload": {
            "code": 0,
            "message": ""
        }
    }
]
```

### Notes

- Master Permission Required
