---
title: Workflow start request
description: Request of start workflow
---

### Endpoint

```bash
PUT /api/workflow/start/
```

### Auth

```bash
Authorization: Bearer ${token}
```

### Query Parameters

| Key | Default |
|-----|---------|
| identity |  |

### Body

Optional. A JSON object of `override` values written to the workflow's `workflow.ini` before it starts. Keys are `env.<step>.<VAR>` or `resource.<step>.<cpu|memory|gpu>`, scoped to a step by its `name`. When omitted, the existing `workflow.ini` (if any) is used unchanged. Overrides are applied only at launch and never modify the definition; an unknown step `name` or an invalid `cpu`/`memory`/`gpu` value fails the start.

```json [Json]
{
    "override": {
        "env.fastqc.THREADS": "8",
        "resource.fastqc.cpu": "8"
    }
}
```

### Notes
