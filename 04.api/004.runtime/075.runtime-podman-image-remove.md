---
title: Runtime podman image remove request
description: Remove a Podman image
---

### Endpoint

```bash
DELETE /api/runtime/podman/image/
```

### Auth

```bash
Authorization: Bearer ${token}
```

| Key | Default |
|-----|---------|
| force | `false` |
| identity |  |

[

        "payload": ""
    }
