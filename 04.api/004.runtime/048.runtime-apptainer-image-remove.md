---
title: Runtime apptainer image remove request
description: Remove an Apptainer image
---

### Endpoint

```bash
DELETE /api/runtime/apptainer/image/
```

### Auth

```bash
Authorization: Bearer ${token}
```

### Query Parameters

| Key | Default |
|-----|---------|
| force | `false` |
| identity |  |

### Response

```json [Json]
[
    {
        "kind": "status",
        "payload": {
            "code": 0,
            "message": ""
        }
    }
]
```

### Notes

- Runtime Permission Required
- Read-Only Permission Restricted
