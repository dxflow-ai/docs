---
title: Runtime singularity image pull request
description: Pull a Singularity image
---

### Endpoint

```bash
PUT /api/runtime/singularity/image/
```

### Auth

```bash
Authorization: Bearer ${token}
```

### Body

```bash
Content-Type: application/json
```

```json [Json]
{
    "force": false,
    "identity": ""
}
```

### Response

```json [Json]
[
    {
        "kind": "status",
        "payload": {
            "code": 0,
            "message": ""
        }
    },
    {
        "kind": "entity",
        "payload": ""
    }
]
```

### Notes

- Runtime Permission Required
