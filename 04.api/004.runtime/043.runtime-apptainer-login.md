---
title: Runtime apptainer login request
description: Sign in to an Apptainer registry
---

### Endpoint

```bash
PUT /api/runtime/apptainer/login/
```

### Auth

```bash
Authorization: Bearer ${token}
```

### Body

```bash
Content-Type: application/json
```

```json [Json]
{
    "password": "",
    "username": ""
}
```

### Response

```json [Json]
[
    {
        "kind": "status",
        "payload": {
            "code": 0,
            "message": ""
        }
    }
]
```

### Notes

- Runtime Permission Required
