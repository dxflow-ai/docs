---
title: Agent artifacts request
description: Request of agent session artifacts
---

### Endpoint

```bash
GET /api/agent/session/artifacts/
```

### Auth

```bash
Authorization: Bearer ${token}
```

### Query Parameters

| Key | Default | Description |
|-----|---------|-------------|
| identity |  | Session identity |

### Response

```json [Json]
[
    {
        "kind": "status",
        "payload": {
            "code": 0,
            "message": ""
        }
    },
    {
        "kind": "entity",
        "payload": {
            "path": "",
            "size": ""
        }
    }
]
```

### Notes

- Agent Permission Required
- Lists user files in the workflow directory (reserved workflow and per-step files are skipped); the session must have a bound workflow.
