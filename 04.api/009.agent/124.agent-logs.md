---
title: Agent logs request
description: Request of agent session logs
---

### Endpoint

```bash
GET /api/agent/session/logs/
```

### Auth

```bash
Authorization: Bearer ${token}
```

### Query Parameters

| Key | Default | Description |
|-----|---------|-------------|
| identity |  | Session identity |
| step | `0` | 1-based step index; `0` for all steps |
| count | `9` | Trailing output lines to keep per step |

### Response

```json [Json]
[
    {
        "kind": "status",
        "payload": {
            "code": 0,
            "message": ""
        }
    },
    {
        "kind": "entity",
        "payload": {
            "step": "",
            "output": ""
        }
    }
]
```

### Notes

- Agent Permission Required
- Returns per-step logs in the agent format — stdout and stderr merged into a tail. The session must have a bound workflow.
