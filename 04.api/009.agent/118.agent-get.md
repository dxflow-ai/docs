---
title: Agent get request
description: Request of get agent session
---

### Endpoint

```bash
GET /api/agent/session/get/
```

### Auth

```bash
Authorization: Bearer ${token}
```

### Query Parameters

| Key | Default | Description |
|-----|---------|-------------|
| identity |  | Session identity |

### Response

```json [Json]
[
    {
        "kind": "status",
        "payload": {
            "code": 0,
            "message": ""
        }
    },
    {
        "kind": "entity",
        "payload": {
            "identity": "",
            "workflow": "",
            "created_at": "",
            "history": [
                {
                    "role": "",
                    "content": "",
                    "tool_calls": [
                        {
                            "id": "",
                            "name": "",
                            "argument": ""
                        }
                    ],
                    "tool_results": [
                        {
                            "id": "",
                            "name": "",
                            "output": "",
                            "failed": false
                        }
                    ]
                }
            ],
            "usage": {
                "input": 0,
                "output": 0,
                "cache_write": 0,
                "cache_read": 0
            }
        }
    }
]
```

### Notes

- Agent Permission Required
- Returns the session state: its context `workflow`, native conversation `history`, and token `usage`.
- `history` is the native conversation — user and assistant `role`s, each turn's `content`, and the assistant's `tool_calls` with their `tool_results` (a `failed` result the agent recovered from). `workflow` is the context (most recently used) workflow, present once the session has one.
- Live per-workflow data — steps, events, logs, stats, and artifacts — comes from the [workflow API](/docs/api/workflow), not the agent endpoints.
- `created_at` here is an RFC3339 timestamp string, unlike the Unix `created_at` in the list and create entities.
