---
title: Agent events request
description: Request of agent session events
---

### Endpoint

```bash
GET /api/agent/session/events/
```

### Auth

```bash
Authorization: Bearer ${token}
```

### Query Parameters

| Key | Default | Description |
|-----|---------|-------------|
| identity |  | Session identity |

### Response

```json [Json]
[
    {
        "kind": "status",
        "payload": {
            "code": 0,
            "message": ""
        }
    },
    {
        "kind": "entity",
        "payload": {
            "time": "",
            "message": ""
        }
    }
]
```

### Notes

- Agent Permission Required
- Returns the bound workflow's events in the agent format; the session must have a bound workflow.
