---
title: Agent stats request
description: Request of agent session stats
---

### Endpoint

```bash
GET /api/agent/session/stats/
```

### Auth

```bash
Authorization: Bearer ${token}
```

### Query Parameters

| Key | Default | Description |
|-----|---------|-------------|
| identity |  | Session identity |
| step | `0` | 1-based step index; `0` for all steps |

### Response

```json [Json]
[
    {
        "kind": "status",
        "payload": {
            "code": 0,
            "message": ""
        }
    },
    {
        "kind": "entity",
        "payload": {
            "step": "",
            "points": [
                {
                    "cpu": "",
                    "mem": ""
                }
            ]
        }
    }
]
```

### Notes

- Agent Permission Required
- Returns the current per-step CPU and memory sample in the agent format; the session must have a bound workflow.
