---
title: Agent list request
description: Request of list agent sessions
---

### Endpoint

```bash
GET /api/agent/session/
```

### Auth

```bash
Authorization: Bearer ${token}
```

### Query Parameters

| Key | Default | Description |
|-----|---------|-------------|
| limit | `-1` |  |
| offset | `0` |  |

### Response

```json [Json]
[
    {
        "kind": "status",
        "payload": {
            "code": 0,
            "message": ""
        }
    },
    {
        "kind": "total",
        "payload": {
            "value": 0
        }
    },
    {
        "kind": "entity",
        "payload": {
            "identity": "",
            "workflow": "",
            "model": "",
            "created_at": 0
        }
    }
]
```

### Notes

- Agent Permission Required
- `model` is the session's latest model call, present once the session has been prompted.
