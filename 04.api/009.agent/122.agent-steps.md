---
title: Agent steps request
description: Request of agent session steps
---

### Endpoint

```bash
GET /api/agent/session/steps/
```

### Auth

```bash
Authorization: Bearer ${token}
```

### Query Parameters

| Key | Default | Description |
|-----|---------|-------------|
| identity |  | Session identity |

### Response

```json [Json]
[
    {
        "kind": "status",
        "payload": {
            "code": 0,
            "message": ""
        }
    },
    {
        "kind": "entity",
        "payload": {
            "name": "",
            "status": "",
            "exit_code": ""
        }
    }
]
```

### Notes

- Agent Permission Required
- Returns the bound workflow's steps in the agent format; the session must have a bound workflow.
