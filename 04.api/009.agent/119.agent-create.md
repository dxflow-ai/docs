---
title: Agent create request
description: Request of create agent session
---

### Endpoint

```bash
POST /api/agent/session/
```

### Auth

```bash
Authorization: Bearer ${token}
```

### Query Parameters

| Key | Default | Description |
|-----|---------|-------------|
| identity |  | Optional; auto-generated when empty |
| workflow |  | Optional; when set, the phase is derived from that workflow's status |

### Response

```json [Json]
[
    {
        "kind": "status",
        "payload": {
            "code": 0,
            "message": ""
        }
    },
    {
        "kind": "entity",
        "payload": {
            "identity": "",
            "type": "",
            "workflow": "",
            "created_at": 0
        }
    }
]
```

### Notes

- Agent Permission Required
- Read-Only Permission Restricted
- With no `workflow`, the session starts in the `design` phase; a bound workflow starts it in `deploy` (or `debug` once a step has failed).
