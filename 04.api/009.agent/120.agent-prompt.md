---
title: Agent prompt request
description: Request of prompt agent session
---

### Endpoint

```bash
POST /api/agent/session/prompt/
```

### Auth

```bash
Authorization: Bearer ${token}
```

### Body Parameters

| Key | Default | Description |
|-----|---------|-------------|
| identity |  | Session identity |
| message |  | Natural-language instruction for this turn |
| model |  | Optional; override the agent model for this turn |

### Response

```json [Json]
[
    {
        "kind": "status",
        "payload": {
            "code": 0,
            "message": ""
        }
    },
    {
        "kind": "entity",
        "payload": {
            "type": "",
            "message": "",
            "tool": "",
            "argument": ""
        }
    }
]
```

### Notes

- Agent Permission Required
- Read-Only Permission Restricted
- Advances the session one turn. Replies stream as the agent's message followed by each tool call and its result (`type` is one of `message`, `tool_run`, `tool_success`, `tool_failed`).
